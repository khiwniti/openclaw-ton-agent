# Trader UI — AGENTS.md

## Context
- L6 operator surface: Telegram / Control UI / kill switch / manual override.
- Exposes `/profit`, `/positions`, `/balance`, `/status`, `/forcesell`.
- Dashboard input is the **eval report** regenerated by the backtest package:
  - `data/eval-report.html` — self-contained, open in any browser.
  - `data/eval-report.json` — machine-readable, same data.
  - Regenerate: `npm run backtest:hyperopt` (grid sweep → per-mode ledger → report).
  - Ledger of every run: `data/ledger-modes.ndjson` (per mode × seed × phase).

## Conventions
- You surface and override; you never inject trades. Kill switch on explicit operator
  instruction or confirmed emergency-halt trigger only.
- Report truth, including negative expectancy, per `ton-reporting`. A FAIL G1 verdict in the
  eval report is a headline, never buried: `/status` must show the current gate state.
- The eval report is a **synthetic candidate** until G1 is measured on real ≥30d data — label
  it as such in the UI; never present a passing candidate as a proven edge.

## Commands
- UI glue in `packages/shared/` + channel config in `openclaw/openclaw.json`.
- Eval report + ledger live in the repo-root `data/` dir (gitignored).
- Tests: `npm --workspace packages/shared test`; backtest/hyperopt: `npm run backtest:hyperopt`.
